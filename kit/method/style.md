# Style

## Documents for people

Written for whoever decides. Short sentences, plain language, no ornament, nothing the reader
does not already know. If it fits in half a page, it does not take a whole one. Reread before
sending.

## The terminal

Anything visual goes inside a code block, at most 62 columns, with box-drawing characters and
simple symbols (✓ ✗ ⚠ ↺ ▸), no emoji, one component per idea, capitals only in titles.
Components: header, greeting, section title, confirmation before starting, access status with
its legend, checklist, findings report.
